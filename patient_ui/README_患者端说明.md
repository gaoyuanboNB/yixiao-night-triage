# 患者端界面 Demo（patient_ui/index.html）

版本：v1.1 演示版（2026-10-08）

## 是什么

单文件 HTML 患者端原型，无需构建、双击即可运行（或静态部署到任意托管）。对应评审意见 #4（补充真实产品）：

- **英文界面为主**，行动卡逐条附中文对照（右上角可切换说明语言）；
- **固定可见的 CALL 995 红色大按钮**（顶栏常驻，任何步骤一键拨打）；
- **一步一问**：两步完成输入（症状 → 年龄/独居/过敏），不老人打长表单；
- **语音输入**：Web Speech API（Chrome/Edge 支持 en-SG / zh-SG）；
- **文字朗读**：行动卡一键 Read aloud，语速放慢（0.92x）适配老年用户；
- **大字号高对比**：正文 ≥22px，行动卡列表带 ✓/⚠/① 视觉标记；
- 行动卡由 rules_definition.json 自动生成的镜像引擎（SG-RULES v2.5，与后端 93 例对拍一致，含否定/跌倒/过敏/出血回归），界面显示 `rules_version / rule_ids / audit_id / llm_override_allowed=false`，与后端契约一致。

## 边界（答辩时如实说明）

- 这是**演示原型**：分级逻辑为前端镜像子集；正式版由后端代码节点 `rule_engine.py` 出结果，前端仅渲染；
- 语音与朗读依赖浏览器能力（Chrome/Edge 桌面与 Android 表现最佳，iOS 需 HTTPS 环境）；
- "Call 995" 按钮使用 `tel:995` 链接，桌面浏览器会提示外呼应用，手机端直接拨号。

## 部署建议（腾讯云）

1. 静态托管：COS + CDN（对象存储开启静态网站）→ 获得 demo URL 二维码；
2. 或轻量应用服务器 Nginx 托管；
3. 部署后：手机实拍扫码 + 演示视频一段（胸痛→995 卡；降压药重复→high 卡）→ 存入 `evidence/`。
